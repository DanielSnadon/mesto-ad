# Mesto

Проект Mesto с валидацией форм, сборкой через Vite и подключением к API.

## Команды

```bash
npm install
npm run dev
npm run build
npm run deploy
```

## Публикация

Для автоматической публикации через GitHub Actions нужно настроить секреты `PUBLIC_PAGES_TOKEN` и `PUBLIC_PAGES_REPO` в приватном репозитории.

Ссылка на опубликованный проект: добавьте ссылку после публикации на GitHub Pages.
